# 项目说明

## 项目目标
本项目旨在将Figma设计稿还原为HTML5网页，实现与设计稿一致的视觉效果，并适配电脑端浏览器。所有图片资源已放置于images文件夹中。

## 页面用途
本页面为展示型网页，内容和布局完全参照Figma设计稿，适合在PC端浏览。

## 布局结构
- 使用HTML5语义化标签（如header、main、footer等）组织页面结构。
- 采用CSS Flexbox和Grid实现响应式布局，确保页面在不同分辨率下都能良好显示。
- 所有图片均引用自images文件夹。

## 样式说明
- 样式全部采用CSS3实现，遵循W3C标准。
- 主要使用Flexbox和Grid进行布局，部分区域根据设计稿使用绝对定位。
- 所有CSS样式均带有详细中文注释，便于理解和维护。
- 颜色、字体、间距等视觉元素严格参照Figma设计稿。

## 适配说明
- 页面宽度适配主流PC显示器（如1920px、1366px等），内容居中显示。
- 采用响应式设计，保证在不同电脑屏幕下显示效果一致。

## 目录结构
- README.md：项目说明文件
- index.html：主页面文件
- style.css：样式文件
- images/：图片资源文件夹

## 后续优化建议
- 可根据实际需求增加交互效果（如按钮悬停、动画等）。
- 可进一步压缩CSS和图片资源，提升加载速度。
- 可考虑增加移动端适配。
