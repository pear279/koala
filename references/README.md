## 归档约定

1. **文档需标注版本与对应代码基线**（git commit 短哈希），便于判断内容是否已过期。
2. **规划类文档在阶段完成后更新状态**，不要新建 v2 文档覆盖，保持单一来源。
3. **设计稿截图**若仅作对照用途，放 `references/design-shots/`，不要留在 `public/`——`public/` 下的文件会被打进构建产物。
4. 文档间引用使用相对路径。
